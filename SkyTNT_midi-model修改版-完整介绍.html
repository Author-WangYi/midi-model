1这是什么

一个跑在自己电脑上的 AI 作曲工具。你说要什么风格，它把音符一个个"写"出来，最后给你一份能直接用的 MIDI 文件。

项目 说明
软件名称 Midi-Model（作者 SkyTNT，开源项目）
它做什么 生成 MIDI 音乐。它的核心是一个约 12 层的 Transformer 模型（LLaMA 架构），把 MIDI 里的音符、力度、乐器、速度等信息拆成 3406 种「词」，像语言模型写文章那样一个字一个字往下预测，拼成一段完整的曲子
怎么用 双击启动后，用浏览器打开一个本地网页界面，填好要求点生成，等几秒到几十秒
给什么 自定义提示：指定乐器、鼓组、BPM、拍号、调号，让它从零开始编
MIDI 续写：丢一个 MIDI 文件进去，它顺着往下写
接着上次：在上一次的结果上继续延伸
出什么 同时给你三样：MIDI 文件（可下载）、WAV 音频（可试听）、网页里滚动的乐谱可视化
一次几个 默认一次生成 8 个方案，挑选满意的那个
跑在哪 完全在你自己的电脑上运算，不上传任何东西，也不用注册账号

2原版为什么不能直接双击，我改了什么

作者发布的是"程序本体"，不是一个"成品软件"。解压后直接双击，通常只会看到一个黑窗口一闪而过。

原版：卡在三道门槛上

  • 门槛一要自己装 fluidsynth
    这是合成声音用的底层库，官方只提供源码，得自己找 Windows 编译版，装完还要配环境变量。
  • 门槛二程序把路径写死了
    程序内部固定去 C:\tools\fluidsynth\bin 找它。装在别的位置？直接崩溃退出，报 FileNotFoundError。
  • 门槛三模型要联网现下
    第一次运行才去 HuggingFace 下载约 990 MB 的模型和音色库。国内网络下这一步经常超时失败，看起来就像"卡住了"。

便携版：这些都替你处理好了

  • 已解决fluidsynth 直接打包进文件夹
    6 MB 的库文件已经躺在包里，不用你下载，也不用管环境变量。
  • 已解决用"自愈式启动器"绕过硬编码
    每次启动自动在 C 盘维护一个几 KB 的目录链接，让程序以为库在它指定的位置。文件夹改名、换盘、换电脑都不用重配，启动器会自己修好。
  • 已解决模型和音色库预先放好
    990 MB 的模型已随包提供，启动和生成都不需要联网。
  • 额外清理删掉了约 3 GB 的无用依赖
    官方包里混入了一套用不上的深度学习运行库。实测确认程序实际用的是 ONNX Runtime 推理，于是把这堆 3 GB 的累赘清了出去。

4三分钟用起来

不需要装任何东西，不需要命令行基础。

  1. 解压到一个你喜欢的文件夹
    放 D 盘、E 盘、桌面都行，文件夹名字随便改，路径里有空格也没关系。建议不要放在 C 盘（省点系统盘空间）。
  2. 双击文件夹里的「启动.bat」
    会出现一个黑色窗口，滚动一段文字后卡住不动——这是正常的，说明服务已经在运行。
    rem 你会看到类似这样的提示： ---------------------------------------- midi-model 便携版 浏览器会自动打开：http://127.0.0.1:7860 关闭这个黑窗口 = 关闭程序 ----------------------------------------
  3. 浏览器自动打开操作界面
    如果没有自动打开，自己开浏览器访问 http://127.0.0.1:7860。首次进入需要等模型加载，会有几十秒的等待。
  4. 点生成，等结果
    在网页里选好乐器、速度、调式等，点生成按钮。等几秒到几十秒，页面上会出现乐谱图、试听音频和 MIDI 下载。
  5. 去 outputs 文件夹拿成品
    生成的 MIDI 会自动存到程序目录下的 outputs 文件夹：
    outputs\ output1.mid output2.mid ... 一直到 output8.mid
    注意：文件名是固定的，下一次生成会覆盖上一次。满意的作品记得第一时间改名或另存到别处。

5用之前必须知道的几件事

都是实测踩出来的，看完能省很多麻烦。

必须
只能双击「启动.bat」，不要直接双击 app.exe。 直接开 exe 会闪退。启动器负责把环境准备好再拉起程序，绕不过去。
必须
关掉那个黑色窗口，就是关掉程序。 程序不会在后台偷偷驻留，也不会开机自启。想彻底退出，关黑窗口即可；浏览器页面可以直接叉掉，不影响。
注意
第一次运行如果提示"无法建立目录链接"，改用管理员身份运行。 程序需要在 C 盘建一个文件夹来"骗过"它内部写死的路径。多数情况下直接双击就行；万一 Windows 权限拦住了，右键 启动.bat → 以管理员身份运行，成功一次以后就正常了。
注意
C 盘会留下一个几 KB 的目录链接，这是正常的，也不是"安装"。 位置是 C:\tools\fluidsynth。它只是个指路牌，指向你解压出来的文件夹，本身不占空间、不写注册表、不装运行库。删掉也没关系，下次启动会自动重建。但程序运行期间需要它存在。
注意
如果装了 360 之类带"c 盘搬家"的安全软件，可能干扰这个链接。 实测发现这类软件会把 C:\tools\fluidsynth 悄悄挪到自己的目录下。如果遇到启动异常或链接反复失效，把程序所在文件夹加入安全软件白名单，或者临时退出它再启动。
放心
全程不需要联网。 模型和音色库已经打包在里面（约 990 MB），启动、生成、试听都在本地完成，不下载任何东西，也不上传你的音乐。断网也能用。
放心
文件夹可以随便改名、随便搬家。 换盘符、改文件夹名、拷到 U 盘带到别的电脑，都不需要重新配置任何东西。只有启动器里一个自动维护的链接会跟着变，你什么都不用做。
放心
杀毒软件报警大概率是误报。 这类用 PyInstaller 打包的程序被误报是常见现象。加信任即可。有条件的话，建议从官方渠道下载后自行核对压缩包。

6常见问题

双击后黑窗口一闪就没了 / 什么都没发生

百分之九十是因为直接双击了 app.exe。请确认双击的是 启动.bat。

如果确实是双击启动.bat 还是闪退，说明文件解压不完整。建议用 7-Zip 或 WinRAR 重新完整解压一遍，别只解压一部分。

黑窗口停住了，光标不闪，是不是卡死了？

不是。模型加载和推理都是"闷着头干活"，中间没有输出。这时打开浏览器访问 http://127.0.0.1:7860 就能看到界面。

首次启动、以及第一次生成时，等待时间会明显长一些（模型要读进内存或显存），之后就快了。

浏览器打不开 / 提示无法访问

先确认黑窗口还在（关掉就等于关程序了）。然后手动访问 http://127.0.0.1:7860。

如果提示端口被占用，说明 7860 这个端口被别的程序（可能是另一个 AI 工具、或另一个副本）占了。关掉它，或者一次只开一个副本。

显卡版启动报错 / 提示找不到 CUDA

显卡版要求 NVIDIA 显卡 + 较新的驱动。请先去 NVIDIA 官网更新显卡驱动，重启后再试。

如果显卡型号比较老（例如早期的 GT 系列、低端 MX 系列），可能本身就不被支持，这种情况请改用 CPU 版 app，功能完全一样，只是慢一些。

生成的曲子很短 / 听起来不完整

默认只生成 2048 个音符事件，这是长度限制，可以在界面里把"generate max n midi events"调大。

另外，一次会出 8 个方案，质量参差不齐是正常的——挑好的用就行。也可以把「接着上次」用起来，一段一段往下接。

两个版本能同时开着吗？

技术上可以，但它们共用同一个 C 盘链接，所以链接只会指向"最后一次启动"的那个副本。程序本身能正常跑，只是因为底层依赖完全相同，不会出问题。

不过为了省心、也为了少占内存和显存，建议一次只开一个。

能删掉包里的东西给它"瘦身"吗？

不要删 _internal 文件夹，那里是程序本体，删了就再也打不开了。

models 文件夹和 soundfont.sf2 是模型与音色库（约 990 MB）。删掉后程序会尝试联网重新下载，国内网络下大概率失败，所以也别删。

outputs 文件夹里是你自己生成的作品，可以随时清理。
